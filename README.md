
# 多输入目标搜索系统

## 项目简介

这是一个基于树莓派Pico和上位机的多输入目标搜索系统，结合了计算机视觉、舵机控制、用户界面和游戏等多种功能。系统能够通过摄像头识别特定颜色和形状的目标，并控制舵机进行自动跟踪，同时提供了丰富的交互界面和娱乐功能。

## 系统架构

系统由两个主要部分组成：

1. **下位机（树莓派Pico）**：负责舵机控制、用户交互和数据显示
2. **上位机（PC）**：负责图像处理、目标识别和串口通信

## 功能特性

### 1. 目标识别与跟踪
- 支持多种颜色识别（红、蓝、绿）
- 支持多种形状识别（圆形、矩形、三角形）
- 基于PID算法的精确舵机控制
- 实时目标跟踪功能

### 2. 用户界面
- OLED显示屏（128x64）显示菜单和状态
- 旋转编码器导航菜单
- 多级菜单系统，支持多种功能切换

### 3. 多模式控制
- **自动模式**：自动识别并跟踪目标
- **手动模式**：通过按键手动控制舵机

### 4. 娱乐功能
- 内置音乐播放器，支持多首预设歌曲
- 贪吃蛇游戏，支持按键控制

### 5. 调试工具
- 摄像头测试工具
- 颜色调参工具，用于优化颜色识别阈值

## 硬件连接

### 树莓派Pico引脚分配
- **OLED显示屏**：I2C接口（SDA-GP2, SCL-GP3）
- **旋转编码器**：A相-GP12, B相-GP13, 按键-GP11
- **方向按键**：上-GP9, 下-GP8, 左-GP6, 右-GP7
- **舵机控制**：X轴-GP14, Y轴-GP15
- **蜂鸣器**：GP17
- **串口通信**：TX-GP0, RX-GP1

### 上位机连接
- 摄像头：USB接口
- 串口：COM9（可在代码中修改）

## 安装与使用

### 环境要求
- **树莓派Pico**：MicroPython固件
- **上位机**：Python 3.x，OpenCV库

### 安装步骤
1. 将`main_pico.py`和`src_for_pico`目录下的所有文件上传到树莓派Pico
2. 在PC上安装Python依赖：
   ```bash
   pip install opencv-python numpy pyserial
   ```
3. 连接硬件设备
4. 运行上位机程序：
   ```bash
   python main_upper_computer.py
   ```

### 使用说明
1. **系统启动**：系统启动后会显示主菜单，可通过旋转编码器导航
2. **目标跟踪**：
   - 进入"Pan&Tilt"菜单
   - 选择"Auto"进入自动模式
   - 选择目标颜色和形状
   - 系统会自动识别并跟踪目标
3. **手动控制**：
   - 进入"Pan&Tilt"菜单
   - 选择"Manual"进入手动模式
   - 使用方向按键控制舵机
4. **音乐播放**：
   - 进入"Music"菜单
   - 选择"Buzz"进入蜂鸣器音乐
   - 从库中选择歌曲并播放
5. **游戏**：
   - 进入"Game"菜单
   - 选择"Greedy Snake"开始游戏
   - 使用方向按键控制蛇的移动

## 调试与优化

### 颜色识别调试
使用`调参工具：颜色调参手动器.py`可以调整颜色识别阈值：
1. 运行调参工具
2. 调整HSV阈值滑块
3. 观察识别效果
4. 将优化后的阈值应用到`colorblob.py`中

### 摄像头测试
使用`摄像头测试.py`测试摄像头功能：
1. 运行测试程序
2. 观察摄像头画面
3. 点击画面可获取坐标信息

## 技术细节

### 通信协议
系统使用自定义串口协议进行通信：
- 帧头：0xFF 0xFE
- 功能字：0xA0（模式控制）或0xB0（数据传输）
- 数据长度：1字节
- 数据内容：可变长度
- 校验和：1字节

### PID控制
PID控制器用于精确控制舵机：
- 比例系数（Kp）：0.15
- 积分系数（Ki）：0
- 微分系数（Kd）：0.05
- 输出限制：100（防止过冲）

### 图像处理
图像处理流程：
1. 图像采集（640x480）
2. HSV颜色空间转换
3. 颜色阈值分割
4. 形态学操作（腐蚀、膨胀）
5. 轮廓检测
6. 形状识别（圆形、矩形、三角形）

## 扩展与定制

### 添加新颜色
1. 在`colorblob.py`中添加颜色阈值
2. 在`main_pico.py`中更新颜色列表
3. 在`main_upper_computer.py`中更新颜色列表

### 添加新形状
1. 在`outsite.py`中添加形状识别算法
2. 在`allin.py`中更新形状识别流程
3. 在`main_pico.py`中更新形状列表

### 添加新歌曲
1. 在`Music.py`中添加新歌曲的乐谱
2. 在`main_pico.py`中更新菜单选项

## 常见问题

1. **串口连接失败**：检查COM端口号和波特率设置
2. **舵机不响应**：检查舵机电源和接线
3. **目标识别不准确**：调整颜色阈值或光照条件
4. **OLED显示异常**：检查I2C连接和地址设置
